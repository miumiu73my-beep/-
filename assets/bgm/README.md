# 『野菜聖女』BGMの追加場所

生成済みMP3を**このフォルダ（`assets/bgm/`）**にアップロードしてください。拡張子・ファイル名は完全一致させます。

| ファイル名 | 使用場面 |
| --- | --- |
| `bgm_title.mp3` | タイトル画面（将来追加予定） |
| `bgm_home.mp3` | 自宅 |
| `bgm_farm.mp3` | 畑 |
| `bgm_laboratory.mp3` | 研究所 |
| `bgm_field.mp3` | 探索フィールド（将来追加予定） |
| `bgm_event.mp3` | 自宅の週末デートイベント |

## 動作
- ユーザーが上部の「BGM ON」を押したときに初めて音声再生を開始します。iPhone/iPadでは再起動後も再生ボタンを押してください。
- 画面／イベントの切替に合わせて曲が自動的に変わります。各曲はループ再生され、開始時に約0.6秒のフェードインを行います。
- BGMのON/OFFと音量はセーブデータの `settings` に保存されます。
- 音源未配置の場合は案内を表示してゲームはそのまま遊べます。6曲がすべて入っていなくても問題ありません。
- MP3の先頭・末尾に無音やエンコード由来の余白がある場合は、音源側で調整してください。
- オフライン再生はブラウザのMP3取得方法（Rangeリクエスト等）やキャッシュ状態に左右され、保証されません。
- ファイルを入れた後は、公開サイトを更新（必要ならPWAを再起動）して動作を確かめてください。

実装：`audio/bgm.js`、`app.js`、`assets/bgm.css`。サービスワーカーはMP3へのRangeリクエストをブラウザの通常処理に委ねます。
